Evaluating Heat Adaptation Interventions

2 Method 1: Time-Stratified Case-Crossover (10 min)

Each case (an encounter) is matched to a handful of control days: same person’s location, same calendar month and year, same day of week as the case day, excluding the case day itself. Because each person is compared only to their own control days, this design controls for anything that is constant for that person and stratum by design (age, insurance, chronic illness, neighborhood). It does not control for a citywide secular trend across the full study period, because that trend operates just as much on the control days as the case day within a given month.

To keep runtimes reasonable in a workshop setting, we subsample cases rather than using all ~75,000+ simulated encounters. Feel free to raise n_cases_per_period and rerun at home.

n_cases_per_period <- 800

pre_cases  <- encounters %>% filter(post == 0) %>% slice_sample(n = n_cases_per_period)
post_cases <- encounters %>% filter(post == 1) %>% slice_sample(n = n_cases_per_period)
sampled_cases <- bind_rows(pre_cases, post_cases)

# lookup table of city-wide daily exposure, used for both case and control days
temp_lookup <- daily_df %>% dplyr::select(date, temp, extreme)

get_control_days <- function(case_date, n_controls = 4) {
  same_month <- format(case_date, "%Y-%m")
  candidates <- temp_lookup %>%
    filter(format(date, "%Y-%m") == same_month,
           wday(date) == wday(case_date),
           date != case_date)
  if (nrow(candidates) > n_controls) {
    candidates <- candidates %>% slice_sample(n = n_controls)
  }
  candidates
}

build_cc_dataset <- function(cases_df) {
  out <- vector("list", nrow(cases_df))
  for (i in seq_len(nrow(cases_df))) {
    case_row <- cases_df[i, ]
    controls <- get_control_days(case_row$date)
    if (nrow(controls) == 0) next

    case_line <- data.frame(
      strat_id = case_row$id, case = 1,
      temp = case_row$temp, extreme = case_row$extreme
    )
    control_lines <- data.frame(
      strat_id = case_row$id, case = 0,
      temp = controls$temp, extreme = controls$extreme
    )
    out[[i]] <- bind_rows(case_line, control_lines)
  }
  bind_rows(out)
}

cc_pre  <- build_cc_dataset(pre_cases)
cc_post <- build_cc_dataset(post_cases)

cat("Pre-period case-crossover rows:", nrow(cc_pre), "\n")
## Pre-period case-crossover rows: 3540

cc_model_pre  <- clogit(case ~ extreme + strata(strat_id), data = cc_pre)

cc_summary <- bind_rows(
  tidy(cc_model_pre,  exponentiate = TRUE, conf.int = TRUE) %>% mutate(period = "Pre (2010-2015)"),
  tidy(cc_model_post, exponentiate = TRUE, conf.int = TRUE) %>% mutate(period = "Post (2016-2020)")
) %>%
  filter(term == "extreme") %>%
  select(period, OR = estimate, conf.low, conf.high, p.value)

print(cc_summary)

What this does and does not tell us. Comparing the pre-period OR to the post-period OR gives an informal before/after signal, similar in spirit to comparing Ahmedabad’s pre-HAP and post-HAP relative risks. But notice that we have not formally tested whether the two ORs differ from each other, and the case-crossover design by itself has no mechanism for netting out a citywide secular trend that shifted between the two multi- year windows. That’s exactly the gap the next method is built to close.
