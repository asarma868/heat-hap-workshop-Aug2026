Evaluating Heat Adaptation Interventions

4 Method 3: Inverse Probability Weighting for Pre/Post Comparison (8 min)

The DiD model above still assumes the population being served didn’t change in ways that matter. But we built in exactly the kind of compositional drift Hess et al. flagged as an unmeasured concern for Ahmedabad: rising Medicaid/uninsured share, rising chronic mental illness prevalence, rising social vulnerability. If those shifts are themselves associated with heat sensitivity, they could bias the DiD estimate in either direction.

The IPW approach: model the probability that a given encounter falls in the post-period as a function of its measured characteristics, then reweight each day’s contribution to the model so that the weighted population looks similar across the pre- and post-periods on those measured characteristics. This does not fix confounding by unmeasured factors (air pollution, healthcare access, publicity effects) any more than the original Ahmedabad study could, but it does directly address the one confounding pathway we actually simulated and can observe.

ps_model <- glm(
  post ~ age + sex + insurance + chronic_mi + svi,
  data = encounters, family = binomial
)

encounters$p_post <- predict(ps_model, type = "response")
marginal_p_post <- mean(encounters$post)

encounters <- encounters %>%
  mutate(
    sw = ifelse(post == 1, marginal_p_post / p_post, (1 - marginal_p_post) / (1 - p_post))
  )

# trim extreme weights, standard practice to avoid a small number of
# observations dominating the model
sw_caps <- quantile(encounters$sw, c(0.01, 0.99))
encounters$sw_trimmed <- pmin(pmax(encounters$sw, sw_caps[1]), sw_caps[2])

summary(encounters$sw_trimmed)
##    Min. 1st Qu.  Median    Mean 3rd Qu.    Max. 
##  0.6386  0.8163  0.9417  0.9973  1.1160  1.9276
# quick covariate balance check: unweighted vs weighted mean SVI and
# chronic_mi by period. If weighting is doing its job, the weighted
# pre/post gap should shrink relative to the unweighted gap.
balance_check <- encounters %>%
  group_by(post) %>%
  summarise(
    unweighted_svi        = mean(svi),
    weighted_svi          = weighted.mean(svi, sw_trimmed),
    unweighted_chronic_mi = mean(chronic_mi),
    weighted_chronic_mi   = weighted.mean(chronic_mi, sw_trimmed)
  )

print(balance_check)

## 1     0          0.476        0.501                 0.297               0.311
## 2     1          0.530        0.503                 0.328               0.312
# aggregate the per-encounter weights up to a day-level average weight,
# then refeed the SAME model_generalized() function used for the DiD
# section, now with weights supplied
day_weights <- encounters %>%
  group_by(date) %>%
  summarise(day_avg_sw = mean(sw_trimmed))

daily_counts_ipw <- daily_counts %>% left_join(day_weights, by = "date")
daily_counts_ipw$day_avg_sw[is.na(daily_counts_ipw$day_avg_sw)] <- 1  # no encounters that day

ipw_irr <- model_generalized(
  dataframe    = daily_counts_ipw,
  outcome_count = daily_counts_ipw$n_encounters_actual,
  exposure     = daily_counts_ipw$extreme,
  intervention = daily_counts_ipw$post,
  weights      = daily_counts_ipw$day_avg_sw
)
ipw_irr
## [1] "0.96 (0.92, 1)"

What to look for. Compare this IRR to the unweighted DiD estimate from Section 2.3. If they’re close, that’s evidence the compositional drift we simulated wasn’t actually biasing the unweighted estimate much. If they diverge, that tells you the population shift was doing some of the work you might otherwise have attributed to the intervention itself, exactly the ambiguity Hess et al. could not rule out for Ahmedabad because they had no individual-level data to weight on.
